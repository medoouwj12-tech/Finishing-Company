# ULTIMATE FITOUT ERP

نظام ويب عربي RTL لإدارة شركات التشطيبات، مبني على Next.js 16 وPostgreSQL عبر Neon، ومجهز للنشر على Vercel.

مدخل التطبيق الذي يستخدمه Vercel هو `app/` و`public/`. توجد ملفات `server.py` و`index.html` و`static/` من النموذج المحلي السابق؛ لا تستخدمها لتشغيل نسخة Vercel.

## الإعداد المحلي

يتطلب Node.js 20.9 أو أحدث، وقاعدة PostgreSQL على Neon.

1. أنشئ مشروعًا في Neon وخذ **pooled connection string** من صفحة الاتصال.
2. انسخ `.env.example` إلى `.env.local` وضع `DATABASE_URL` وكلمة مرور قوية وفريدة في `ADMIN_PASSWORD`، مع اسم وبريد المالك. لا ترفع `.env.local` إلى GitHub.
3. ثبّت الحزم وشغّل مخطط قاعدة البيانات وأنشئ حساب المالك:

```powershell
npm install
npm run db:migrate
npm run db:create-admin
npm run dev
```

افتح `http://localhost:3000`. ملف الهجرة قابل لإعادة التشغيل، لكنه ينشئ الجداول ولا يضيف بيانات تجريبية.

## النشر عبر GitHub وVercel

ارفع المستودع إلى GitHub، ثم استورده في Vercel. اترك Framework Preset على Next.js وأضف متغيرات الإنتاج في Vercel Project Settings → Environment Variables:

- `DATABASE_URL`: pooled Neon PostgreSQL connection string.
- `ADMIN_NAME`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`: تستخدم لإنشاء المالك مرة واحدة محليًا؛ لا حاجة لإتاحتها لخادم Vercel بعد تجهيز المستخدم.

شغّل `npm run db:migrate` من جهازك بعد ضبط `DATABASE_URL` على قاعدة Neon، ثم شغّل `npm run db:create-admin` مرة واحدة. بعدها انشر المشروع. لا تضع بيانات الاتصال في متغير يبدأ بـ `NEXT_PUBLIC_`.

## ما يغطيه المشروع حاليًا

- تسجيل دخول ببريد وكلمة مرور، كلمات المرور مخزنة بـ bcrypt، جلسات عشوائية مخزنة بصيغة SHA-256 داخل PostgreSQL، Cookie آمنة، وتعطيل مؤقت بعد محاولات دخول فاشلة.
- أدوار وصلاحيات على API، مع أدوار المالك والمدير ومدير المشروع والمهندس والمحاسب والمشتريات والمخزن والموارد البشرية والمبيعات والموظف.
- العملاء، الزيارات، المشاريع، بنود المقايسة والقياسات، العقود والدفعات وأوامر التغيير، الفواتير والاعتماد والتحصيل والإشعارات الدائنة.
- الموردون، طلبات الاحتياج، أوامر الشراء، الاستلام وحركات المخزون، مدفوعات الموردين، العمالة والمقاولون، الموظفون والحضور والإجازات ومسيرات الرواتب، المهام وتقارير الموقع والاستلام والتسليم.
- دليل حسابات ابتدائي، قيود مزدوجة لإصدار الفاتورة واعتمادها والتحصيل والمصروفات والمشتريات، وتقارير مالية أساسية وميزان مراجعة.
- لوحة مؤشرات محسوبة من قاعدة البيانات، طباعة الفاتورة من المتصفح، وتصدير الجداول إلى CSV.

## ملاحظات مهمة قبل الاستخدام الفعلي

هذه نسخة تشغيلية واسعة ومهيأة للربط والنشر، وتحتاج اختبارًا على قاعدة Neon فعلية ومراجعة محاسب ومستخدمين من الشركة قبل إدخال دفاتر مالية حقيقية. لا يوجد اتصال بقاعدة Neon أو بيانات اعتماد في مساحة العمل حاليًا، لذلك لم أستطع التحقق من SQL أو بناء Next.js في هذه الجلسة. شبكة npm في البيئة أعادت `EACCES` عند محاولة تنزيل الحزم، ولم يتوفر `node_modules` محلي.

لم تكتمل بعد كل متطلبات ملف الطلب الأصلي. على وجه الخصوص: ملفات المرفقات تحتاج مزود تخزين مثل Vercel Blob، لا يوجد ربط فعلي لرسائل WhatsApp أو البريد أو الفاتورة الإلكترونية المصرية، وقوالب PDF/تصدير Excel الأصلي والنسخ الاحتياطية المجدولة لم تنفذ. ميزات الرواتب والحضور والإجازات وبعض جداول التشغيل لها مخطط قاعدة بيانات وواجهات API أولية لكن يلزم استكمال شاشاتها وسير اعتمادها. التقارير المحاسبية أولية ولا تمثل إقرارًا ضريبيًا أو ميزانية معتمدة. الفاتورة المطبوعة مستند داخلي، وليست فاتورة إلكترونية ضريبية معتمدة.

لا تنشر الرابط للعامة قبل ربط Neon واختبار الهجرة ومسار الدخول والقيود بالأدوار المستخدمة. لا تشارك `DATABASE_URL` أو كلمة مرور المالك في المحادثة؛ أضفهما مباشرة إلى `.env.local` ثم إلى إعدادات Vercel.
